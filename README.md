# cardapiodigital.emma
CARDÁPIO DIGITAL: Escola Municipal Machado de Assis - Ituiutaba/MG

Aplicação web para divulgação do cardápio da Escola Municipal Machado de Assis, desenvolvida como parte do Projeto Integrador de Tecnologia da Informação II.
O Cardápio Digital – EMMA foi desenvolvido com o objetivo de facilitar o acesso às informações sobre a alimentação escolar por alunos, responsáveis e profissionais da escola. A aplicação apresenta uma interface simples e responsiva, permitindo que as informações sejam acessadas por diferentes dispositivos.

OBJETIVO - Desenvolver uma aplicação web para divulgação do cardápio da alimentação escolar, facilitando o acesso às informações por parte dos alunos, responsáveis e profissionais da Escola Municipal Machado de Assis.

TECNOLOGIAS UTILIZADAS
HTML5 – estruturação das páginas;
CSS3 – estilização e identidade visual;
JavaScript – interatividade e validação de formulários;
Bootstrap 5.3.3 – componentes e responsividade;
Visual Studio Code – ambiente de desenvolvimento;
GitHub – armazenamento e versionamento do projeto.

FUNCIONALIDADES -  
A aplicação foi desenvolvida com as seguintes funcionalidades e páginas:
Página inicial;
Página de cardápio;
Informações sobre o PNAE;
Página de contato;
Cadastro de usuários;
Login;
Área para envio de sugestões;
Interface responsiva para diferentes tamanhos de tela.
Algumas funcionalidades e páginas ainda estão em desenvolvimento e receberão melhorias nas próximas etapas do projeto.

INSTALAÇÃO - 
A versão atual da aplicação não necessita de instalação de dependências ou banco de dados. 
Para utilizar o projeto localmente:
Faça o download do repositório ou clone o projeto.
Abra a pasta do projeto no Visual Studio Code.
Verifique se os arquivos e pastas estão organizados corretamente.

EXECUÇÃO - 
Para executar a aplicação, abra o arquivo: site.html. O arquivo pode ser aberto diretamente em um navegador, como Google Chrome, Microsoft Edge ou Mozilla Firefox. Durante o desenvolvimento, também pode ser utilizado o Live Server no Visual Studio Code para executar a aplicação localmente e visualizar as alterações realizadas.

UTILIZAÇÃO - 
Ao acessar a aplicação, o usuário poderá navegar pelas opções disponíveis no menu principal. A página inicial apresenta o projeto e permite acessar as demais áreas da aplicação. As páginas de cardápio e PNAE apresentam informações relacionadas à alimentação escolar. As áreas de cadastro e login são destinadas ao acesso dos usuários, enquanto o espaço de sugestões permite o envio de opiniões sobre a alimentação escolar.

RESPONSIVIDADE - 
A aplicação utiliza o Bootstrap 5.3.3 e CSS3 para adaptar a interface a diferentes tamanhos de tela, possibilitando sua utilização em computadores, tablets e smartphones.
